# Группы

Группа — небольшой общий чат для компании. Она не даёт навыков и не требует качать уровень как например [кланы](/feature/clans).

| Команда | Что делает |
| --- | --- |
| `/group create <название>` | Создаёт группу, вы становитесь её лидером |
| `/group invite <ник>` | Приглашает игрока в сети |
| `/group accept <название>` | Принимает приглашение |
| `/group deny <название>` | Отклоняет приглашение |
| `/group kick <ник>` | Исключает участника, в том числе офлайн |
| `/group leave` | Выходит из группы |
| `/group delete` | Распускает группу |

Одновременно можно состоять в одной группе. Приглашать и исключать участников может лидер. Лидер не может просто выйти, оставив группу без управления: для него есть роспуск.

Для общения с участниками переключите [канал чата](/feature/chat) командой `/chat mode group`. `/gc <текст>` отправит одно сообщение в общий чат, не выводя вас из группового режима. Группы временные и не сохраняются после перезапуска сервера.
