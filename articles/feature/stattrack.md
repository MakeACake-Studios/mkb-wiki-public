# Стат-трэк

Ещё один способ покрасоваться циферками, но теперь уже на собственных инструментах. За небольшое количество вечно-золотых можно приобрести "Стат-трэк" на выбранный вами инструмент, вдобавок получая цветное переименование, чтобы закрепить уникальность избранного вами предмета
