# Невидимые рамки

С помощью ножниц можно "обрезать" рамку (shift + пкм), сделав её невидимой. Это позволит убрать страшную обводку вокруг вложенного предмета и использовать для более детального декорирования

::youtube{id="hTBqCix5q9k"}

Пустая обрезанная рамка отмечается частицами, чтобы её можно было найти; когда положите предмет, останется только он. Обратное действие тем же кликом не предусмотрено.

Проверка места установки рамок менее строгая, чем в ваниле. Это помогает с декором в тесных местах, но не означает, что рамку можно повесить куда угодно без подходящей поверхности.
