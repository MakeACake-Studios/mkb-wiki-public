# Топы

Единая система лидербордов сервера, где можно посмотреть, кто вырывается вперёд по разным показателям.

- **Топ по донату** ( `/top donations` ) - лучшие спонсоры проекта.
- **Топ по рыбалке** ( `/top fishing` ) - самые удачливые рыбаки текущего [сезона](/feature/season).
- **Топ по наигранному времени** ( `/top playtime` ) - те, кто проводит на сервере больше всего времени.

Полный список доступных топов со ссылками показывает команда `/top` или `/top list`.
