# Друзья

`/friend` или `/friend gui` открывает список друзей. Добавление взаимное: сначала один игрок отправляет заявку, затем другой её принимает.

| Команда | Что делает |
| --- | --- |
| `/friend add <ник>` | Отправляет заявку игроку в сети |
| `/friend accept <ник>` | Принимает заявку |
| `/friend deny <ник>` | Отклоняет заявку |
| `/friend remove <ник>` | Удаляет друга, даже если тот не в сети |
| `/friend list` | Показывает список друзей |

Для принятия и отклонения заявки второй игрок должен быть в сети. Себя добавить нельзя; повторная заявка уже добавленному другу ничего не изменит. Дружба не добавляет человека в [группу](/feature/groups) или [клан](/feature/clans) автоматически.
