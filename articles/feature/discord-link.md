# Привязка Discord

Свяжите свой игровой аккаунт с Discord, чтобы объединить игру и наше сообщество в одном профиле. Привязка делается в пару шагов:

1. В игре введите `/link discord <ваш тег>` (например `/link discord @nickname`).
2. В ответ придёт код подтверждения - кликните по нему, чтобы скопировать.
3. Отправьте этот код боту `@MakeABuilders#4927` в личные сообщения Discord.

Передумали? Отвязать аккаунт можно командой `/unlink`.

:::info{title="Один аккаунт - один Discord"}

К одному Discord можно привязать только один игровой аккаунт. Если ваш Discord уже занят другим аккаунтом, привязка не пройдёт - сначала отвяжите старый.

:::
