# Привязка Discord

Свяжите свой игровой аккаунт с Discord, чтобы объединить игру и наше сообщество в одном профиле. Привязка делается в пару шагов:

1. В игре введите `/link discord` — тег или ник Discord указывать не нужно.
2. В ответ придёт код подтверждения - кликните по нему, чтобы скопировать.
3. Отправьте боту MakeABuilders в личные сообщения Discord только шестизначный код. Используйте бота с нашего Discord-сервера, а не случайный аккаунт с похожим именем.

Код действует 5 минут. Если не успели, выполните команду ещё раз: новый код заменит старый. Бот принимает не больше 5 попыток проверки за минуту.

Передумали? Отвязать аккаунт можно командой `/unlink discord` в игре или `/unlink` в личном чате бота. Остальные команды бота собраны [здесь](/feature/bots).

Если команда сообщает, что привязка недоступна, повторите позже или обратитесь к администрации: без работающего сервиса привязки подтвердить аккаунт не получится.

:::info{title="Один аккаунт - один Discord"}

К одному Discord можно привязать только один игровой аккаунт. Если ваш Discord уже занят другим аккаунтом, привязка не пройдёт - сначала отвяжите старый.

:::
