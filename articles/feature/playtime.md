# Игровое время

Хотите узнать, сколько времени вы (или кто-то другой) провели на сервере? Для этого есть набор простых команд. Без указания ника они расскажут о вас, а с ником - о другом игроке.

| Команда | Что показывает |
| --- | --- |
| `/timeplayed [ник]` | Сколько часов наиграно на сервере |
| `/firstseen [ник]` | Дата самого первого входа |
| `/lastseen [ник]` | Дата последнего входа (или отметка, что игрок сейчас онлайн) |

Все эти данные также собраны в одном месте - в карточке [профиля игрока](/feature/profile).
